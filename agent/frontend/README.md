# HireAce — Web app

Next.js app for HireAce: voice session UI, Approve/Deny cards for the gatekeeper,
and a live view of the PC for phones ("My PC"). Mobile responsive.

Based on LiveKit's [agent-starter-react](https://github.com/livekit-examples/agent-starter-react) template.

See the [root README](../../README.md) for setup and configuration.

```bash
pnpm install
pnpm dev       # http://localhost:3000 (start the agent first)
pnpm build
```
